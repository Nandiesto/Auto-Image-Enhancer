# Auto Image Enhancer

Auto Image Enhancer is a simple GUI-based application built with Python and OpenCV to enhance images automatically. It intelligently adjusts brightness, contrast, saturation, and sharpness while preserving the original aspect ratio. The app provides a side-by-side comparison of the original and enhanced image and allows users to save the final result.

## Features
- **Automatic Image Enhancement** – Adjusts brightness, contrast, saturation, and sharpness based on image analysis.
- **Aspect Ratio Preservation** – Ensures the image is displayed correctly without distortion.
- **Side-by-Side Comparison** – Shows both the original and enhanced images.
- **Image Saving Option** – Allows users to save the enhanced image in their preferred location.
- **Minimal & Aesthetic UI** – A clean, user-friendly interface for a smooth experience.
- **Loading Animation** – Displays a progress bar while processing the image.
