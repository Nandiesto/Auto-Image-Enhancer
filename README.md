# Auto Image Enhancer

Auto Image Enhancer is a simple GUI-based application built with Python and OpenCV to enhance images automatically. It intelligently adjusts brightness, contrast, saturation, and sharpness while preserving the original aspect ratio. The app provides a side-by-side comparison of the original and enhanced image and allows users to save the final result.

## Features
- **Automatic Image Enhancement** – Adjusts brightness, contrast, saturation, and sharpness based on image analysis.
- **Aspect Ratio Preservation** – Ensures the image is displayed correctly without distortion.
- **Side-by-Side Comparison** – Shows both the original and enhanced images.
- **Image Saving Option** – Allows users to save the enhanced image in their preferred location.
- **Minimal & Aesthetic UI** – A clean, user-friendly interface for a smooth experience.
- **Loading Animation** – Displays a progress bar while processing the image.

## Installation Guide
### Prerequisites
- **Python 3.6 or later** must be installed. You can download it from [Python's official site](https://www.python.org/downloads/).

### Clone the Repository
To get started, open a terminal or command prompt and run:
```bash
git clone https://github.com/Nandiesto/auto-image-enhancer.git
cd auto-image-enhancer
```

## How to Use
### 1️⃣ Open the Application  
- Run `python main.py` to start the program.
- The main window titled **"Auto Image Enhancer"** will appear.

### 2️⃣ Select an Image  
- Click the **"Select Image"** button.
- Choose an image file (`.jpg`, `.png`, `.jpeg`) from your computer.
- A **loading bar** will appear while the image is being processed.

### 3️⃣ View the Enhanced Image  
- Once processing is done, a **side-by-side comparison** of the original and enhanced image will be displayed.
- The images will be resized to fit the screen while maintaining their aspect ratio.

### 4️⃣ Save the Enhanced Image  
- Click the **"Save Image"** button to store the enhanced image.
- A window will open, allowing you to choose the save location and file format (`.jpg` or `.png`).

### 5️⃣ Exit the Application  
- Click **"Close"** to exit the application.
