# Auto Image Enhancer

Auto Image Enhancer is a simple GUI-based application built with Python and OpenCV to enhance images automatically. The program adjusts brightness, contrast, saturation, and sharpness while maintaining the original aspect ratio. It also provides a side-by-side comparison of the original and enhanced image.

## Features
- Automatically enhances images by adjusting brightness, contrast, saturation, and sharpness.
- Preserves the original aspect ratio.
- Provides a side-by-side comparison of the original and enhanced image.
- Allows saving the enhanced image to a preferred location.
- User-friendly GUI with a minimal and aesthetic design.
- Loading animation while processing the image.
